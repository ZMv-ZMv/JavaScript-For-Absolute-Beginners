4. innerText & TextContent.mp4

innerText: sirve para tratar lo que está dentro de un elemento pero como texto, las etiquetas o códigos especiales se muestran como texto, también se tiene en cuenta el estilo. No devolverá el texto que ha sido "escondido" con CSS (con 'display: none' o 'visibility: hidden'). En segundo lugar, 'innerText' devuelve el texto con los saltos de línea y el espaciado que se ve en el navegador.

texContent: sirve para establecer o devolver el contenido de texto de un nodo y todos sus descendientes. Si se usa para establecer el texto, eliminará todos los nodos hijos y los reemplazará con un solo nodo de texto con el valor especificado.

innerHTML sirve para tratar un elemento con tus etiquetas procesadas como etiquetas, es decir, como código, incluye los espacios en blanco y saltos de línea. 'innerHTML' es la única propiedad de las tres que permite manipular el HTML dentro de un elemento. Esto significa que puedes usar 'innerHTML' para agregar, eliminar o modificar etiquetas HTML dentro de un elemento. 'textContent' y 'innerText', por otro lado, sólo te permitirán manipular el texto.

8. Create Element.mp4

El método createElement sive para crear elementos (etiquetas) en HTML. necesita dos argumentos uno la etiqueta (como texto) y otro no obligatorio, unas opciones (no importantes...)

let element = document.createElement(tagName, [options]);

Este método no agrega el elemento a la página, lo que hace es crearlo en memoria, es por ello que es neceario asignar el restulado de este método a una variable. Para agregar este nuevo elemento con un contenido a la página web son mínimos dos pasos más:

  1. Utilizar métodos como textContent o createTextNode para agregarle contenido al elemento.
  2. Utilizar métodos como appendChild o append para agregar el elemento a la página web.
